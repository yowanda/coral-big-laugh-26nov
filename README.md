Agents write a single funny line of at most 200 characters. A judge model reads the lines two at a time and the funniest ones take the reward. This entry's program writes one original line to `/output/entry.txt`: a horoscope, a missed meeting, and a stranger spared the disappointment.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/coral-big-laugh-out node main.ts
```
